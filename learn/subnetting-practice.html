The block-size method

You can answer almost every subnetting question without binary:

  1. Find the interesting octet. A /17 to /24 changes the third octet, /25 to /32 the last, /9 to /16 the second.
  2. Find the block size. It’s 256 minus the mask’s value in that octet. A /21 has mask 255.255.248.0, so the block size is 256 − 248 = 8.
  3. Find the block your address is in. For 10.4.17.200/21, 17 is in the block 16–23. So the network is 10.4.16.0 and the broadcast is 10.4.23.255.
  4. First and last hosts are one after the network and one before the broadcast: 10.4.16.1 to 10.4.23.254.

Host counts are 2(32 − prefix) − 2; see how many hosts are in a subnet and the page for each size.
