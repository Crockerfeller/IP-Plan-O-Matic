How many hosts are in a subnet?

A subnet with prefix length /n has 232−n addresses. Subtract 2 for the network and broadcast addresses and you have the usable hosts.

The formula

Usable hosts = 2(32 − prefix) − 2. A /24 has 28 = 256 addresses, so 254 usable hosts. A /26 has 64 addresses and 62 hosts. A /30 has 4 addresses and 2 hosts, which is why it was the classic size for a link between two routers.

The exceptions: /31 and /32

A /31 has only two addresses and no room for a broadcast, so RFC 3021 lets both be used on a point-to-point link. It saves half the addresses of a /30. A /32 is a single address, used for loopbacks and host routes.

Clouds use more addresses

Cloud networks reserve extra addresses in every subnet for their router and DNS. A /24 has 251 usable addresses in AWS and Azure, 252 in Google Cloud and 253 in Oracle Cloud. See the CIDR cheat sheet for every size, or the guides for AWS, Azure, Google Cloud and Oracle Cloud.

Picking a size from a host count

Find the smallest prefix whose usable hosts cover what you need, plus room to grow. 50 hosts fit in a /26 (62), 100 in a /25 (126), 300 in a /23 (510). The VLSM guide shows how to do this for a whole list of networks at once.

Type the base network into the planner, click Divide until you reach the size you need, and the host count shows on every row.
