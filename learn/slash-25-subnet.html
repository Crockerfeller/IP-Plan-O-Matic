/25 subnet (subnet mask 255.255.255.128)

A /25 is 128 IPv4 addresses, with subnet mask 255.255.255.128 and 126 usable hosts.

Subnet mask255.255.255.128
Wildcard mask0.0.0.127
Binary mask11111111.11111111.11111111.10000000
Total addresses128
Usable hosts126 (minus network and broadcast)
/25s in a /242

What a /25 is used for

Half of a /24: 126 hosts, for a department, floor or server network.

Where /25 subnets start

The block size is 128 in the last octet: a /25 always starts at 0, 128.

Every /25 inside 192.168.1.0/24.

SubnetUsable rangeBroadcast
192.168.1.0/25192.168.1.1 – 192.168.1.126192.168.1.127
192.168.1.128/25192.168.1.129 – 192.168.1.254192.168.1.255

Usable addresses in the cloud

Clouds reserve more addresses than the network and broadcast: 5 in AWS and Azure, 4 in Google Cloud, 3 in Oracle Cloud.

CloudUsable addresses
AWS VPC123
Azure VNet123
Google Cloud VPC124
Oracle Cloud VCN125

Splitting and joining

A /25 splits into 2 /26s, 4 /27s, 8 /28s. Two /25s that sit side by side, starting on a multiple of 256 addresses, join into one /24.
