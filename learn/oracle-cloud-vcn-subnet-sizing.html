Oracle Cloud (OCI) VCN subnet sizing

Oracle Cloud reserves only 3 addresses per subnet, the fewest of the big clouds.

The 3 reserved addresses

In 10.3.0.0/24, OCI keeps the first two addresses, 10.3.0.0 (network) and 10.3.0.1 (default gateway), and the last, 10.3.0.255 (broadcast).

Sizes

VCN CIDR blocks can be from /16 to /30, and a VCN can have more than one block. The smallest subnet, a /30, leaves a single usable address.

Regional or AD-specific subnets

Oracle recommends regional subnets, which span every availability domain in the region, so instances in any AD can use them. AD-specific subnets are the older model.

The planner applies OCI’s 3 reserved addresses and /30 minimum, and exports Terraform for oci_core_vcn and oci_core_subnet.
